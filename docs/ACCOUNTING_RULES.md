# 账务规则

## 领域不变量

- 正式账本以 `Account -> Transaction -> Posting` 为核心结构。
- 每个正式交易的有效分录必须按币种平衡。
- 余额由有效分录重放得到，不由展示层直接覆盖历史。
- 金额必须使用精确表示，并明确货币与精度。
- 来源事实、候选、人工确认和正式账目必须能够分别追溯。
- 对账状态描述证据关系，不改变账户余额。

## 交易类型

用户账本提供支出、收入、转账和借贷四类业务入口。业务入口用于组织录入和统计，底层可以产生一条或多条结构化分录。

## 来源与证据

导入记录首先保存为不可变来源事实。解析器、匹配器和约束规则只能生成候选，并附带来源、理由和置信度；正式账目需要明确确认。

## 修正与经济事件

录入错误使用版本替换保留修改历史。退款、真实冲回、手续费、利息等会影响经济事实的行为使用独立交易或分录表达，不覆盖原始事实。

## 当前规则范围

本文件当前只固定不会随界面变化的最小不变量。详细分类、时间、余额调整、复杂交易、预付和对账规则将在经过决定记录核验后分批迁入。
