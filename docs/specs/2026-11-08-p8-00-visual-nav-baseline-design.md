日期：2026-11-08。批准依据：用户 2026-11-08 对 [视觉基线草案 v1](local/p8-00-design/P8-00-视觉基线草案-v1.md（gitignored 裁决材料）) 三事项的「All」裁决（会话内批准，草案为裁决材料留档于 `local/`，不进仓库）。设计画布 `local/p8-00-design/01-首页.pen`…`06-账户流水.pen`（gitignored，本规格以文字转述其结构与 token，不依赖画布文件存在）。

## 1. 导航基线（事项一、二）

### 1.1 三 Tab

底栏为三项：`HOME`（首页）、`ACCOUNTS`（账户/资产）、`ANALYSIS`（分析）。`P503Tab.IMPORT` 从底栏移除。

对既有契约的修订清单（实施批逐条处置，本规格冻结目标状态）：

| 既有面 | D-146 登记的语义 | 本基线的处置 |
| --- | --- | --- |
| `P503Tab.IMPORT` | 第四 Tab，导入面的权威承载 | 移除出底栏枚举；导入面保留为独立路由目标 |
| `OverviewEmpty.importReview` | IMPORT Tab 的可选投影 | 投影保留，改由导入路由承载 |
| IMPORT 事件族（含 `IMPORT-Back` 的有意 ISE、`OpenImportTab` 中立请求） | 按 P7-04 表 6.2a 冻结 | 导入仍可达时语义不变；事件族不删除，处置方式在实施批逐条登记 |

## 2. 屏幕基线（六屏）

以下为各屏的内容组织（暗色示例；布局尺寸是提议，落地批校准）：

1. **首页**：顶栏（☰ / ··· / 头像）；大标题＝当前账本名＋⌄（顶栏账本选择器已裁形态）；搜索胶囊；月份行（‹ › ＋「收支日历」胶囊）；摘要卡（当前月支出大字＋收入/结余副行＋三点滑动指示：支出/收入/结余三页）；日期分组流水（分组头带当日合计、可折叠；行＝分类彩色圆图标＋标题＋时间·账户＋金额）；底部三 Tab dock＋独立圆形＋。
2. **资产**：净资产卡**按币种分块**（每块＝该币种「资产−负债」大字＋资产/负债副行；跨币种不合并、不折算、不用汇率）；总借入/总借出双卡；账户分组列表（「资产 · N 个账户」「负债 · N 个账户」；行＝名称＋类型＋余额，数据口径与现行 `P503CatalogManagementScreen` 一致）。
3. **分析**：顶栏（☰ / 筛选胶囊 / 头像）；大标题「分析」；周期分段（周/月/年/全部/范围）＋日期区间行；收支统计 2×2（支出/收入/结余/日均支出）；分类排行条（名称＋金额＋占比＋进度条）。**周期分段与日均支出是呈现占位**：其查询能力、口径与规模边界归 P8-06；本基线只锁信息组织。
4. **交易详情**（二级）：返回＋标题＋···；旗帜行（方向 pill 等状态标记）；金额＋`币种 · 发生 …（UTC+8）`副行；账目信息卡（分类/账户/发生时间/统计时间/备注）；来源卡（只读声明）；版本历史折叠行（只读）。**不设编辑/作废/修正入口**——修正与作废语义归 P7-05 既有设计，入口形态届时另批。转账双腿显示不在本基线（原型亦未覆盖）。
5. **侧栏**（抽屉）：标题「账本与数据」＋当前账本副行＋关闭钮；「账本」组（账本管理、新建账本）；「数据」组（备份与恢复、回收站、导入账单）。账本管理/新建账本为占位入口，行为归账本专项（U1–U7，设计未批）。
6. **账户流水**（二级）：返回＋···；账户余额大字＋「名称 · 类型 · 币种」副行；月份行同首页；日期分组流水同首页；底部预留 P8-01 对账入口位（本基线不实现）。

**空态/错误态/长内容**：本基线只锁「有数据正常态」布局；四态样本（真实/空/错误/长内容）与浅色主题、字体放大、TalkBack 样本在落地批补齐——这是 P8-00 出口条件的一部分，不是可选装饰。

**玻璃层关系**：本基线全部为不透明暗色面；`GLASS_ENABLED` 玻璃层（D-136）不与本基线冲突——落地批保持玻璃层现有回退结构，暗色 token 作为其下方实色层。

## 4. 净资产口径（事项三，冻结）

资产页净资产 = **按币种分块**：每块显示该币种内「资产账户余额和 − 负债账户余额和」，整数 minor units 精确运算；不同币种不合并、不折算、不引入汇率；无该币种持仓则不显示该块。

- 依据：折算需汇率取值与舍入，产生近似展示值，与「金额精确」铁律（README 核心原则）冲突；同币种加总保持精确。
- 本口径不新增查询端口以外的任何账务行为；需要的「按币种分组余额和」读模型在落地批核对现行 `AccountCurrencyBalance` 投影是否已覆盖，不足则在该批内补只读投影（零 DDL 预期，若有 schema 需求另行开门）。
- 未来跨币种折算（即时/历史汇率）不在本规格，由汇率设计门另行裁决。
