# 黄金测试

## 目标

黄金测试用于冻结账务行为，使后续 Kotlin 核心、导入器和对账引擎能够与已确认结果逐项比较。

## 验收层级

### 匿名规则场景

使用完全合成的账户、金额、时间和来源记录，覆盖可以进入公开仓库的核心规则。

### 本地真实来源场景

使用不进入 Git 的真实来源资料验证解析和历史重建。公开仓库只记录匿名场景编号、输入类别和验收维度。

## 每个案例的验收内容

- 输入来源与初始账户状态。
- 正式交易及逐条分录。
- 账户余额和统计影响。
- 来源证据、匹配结果和对账状态。
- 需要人工确认的步骤。
- 不应发生的副作用。

## 数据安全

公开测试不得包含真实姓名、账号、电话、订单标识、商户标签、余额锚点或可逆推出个人关系的数据。

## 通过标准

- 按交易和分录比较，不只比较最终余额。
- 金额精确、分录平衡、证据关系可解释。
- 关闭网络、同步和 AI 后仍能完成全部核心验收。
