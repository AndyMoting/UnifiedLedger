# 项目章程

## 项目使命

建立一套可信、可解释、可重放的个人账务系统，使记账、账单导入和对账审计共用同一账务事实，而不是形成相互矛盾的三套数据。

真正的 3-in-1 指记账、账单导入和对账审计构成一个产品内的三种能力，不是三个独立产品。手工记录、导入记录和核验结果最终服务于同一正式账本。

## 事实边界

- 正式账本是余额、统计和报表的唯一事实来源。
- 来源记录保存外部证据，不能直接冒充正式账目。
- 解析、规则和智能能力只能生成带依据的候选。
- 候选经过明确确认后才能创建或替换正式分录。
- 对账记录说明正式分录与证据的核验程度，不改变账面余额。

## 范围

- 支出、收入、转账和借贷的日常记录。
- 多来源账单导入、标准化、去重和人工确认。
- 账户余额重放、差异发现、证据关联和对账审计。
- Android 日常客户端与 Desktop 批量工作台共享业务核心。
- 本地优先运行，并为后续可选同步和 AI 能力保留边界。

## 当前阶段

当前阶段的第一目标是冻结账务规则、通过黄金案例，并形成可解释、可重放的账务核心。客户端完整界面不早于核心规则和导入对账闭环。

第一目标以逐交易、逐分录和逐证据的可验证结果衡量，不以页面数量、支持平台数量、自动化程度或视觉完成度衡量。

## 当前非目标

- 完整 Android 和 Desktop 产品界面。
- Web、iOS 和其他扩展平台。
- 云同步服务和并发冲突协议。
- 具体 AI 服务接入。
- 会员、支付、广告、增长和遥测。
- 一次性迁移全部历史数据。

## 成功标准

- 正式交易按币种形成平衡分录。
- 余额可以从有效分录确定性重放。
- 来源事实、推断、人工确认和正式账目能够区分。
- 内部转账不会被统计为真实收入或支出。
- 修改、退款、冲回和对账均保留可解释历史。
- 匿名黄金案例在离线且未启用同步和 AI 时全部通过。
- 没有同步、AI 或外部参考资料时，核心仍可完成记账、导入、余额重放、报表和对账。
