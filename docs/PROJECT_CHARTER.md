# 项目章程

## 项目使命

建立一套可信、可解释、可重放的个人账务系统，使记账、账单导入和对账审计共用同一账务事实，而不是形成相互矛盾的三套数据。

## 范围

- 支出、收入、转账和借贷的日常记录。
- 多来源账单导入、标准化、去重和人工确认。
- 账户余额重放、差异发现、证据关联和对账审计。
- Android 日常客户端与 Desktop 批量工作台共享业务核心。
- 本地优先运行，并为后续可选同步和 AI 能力保留边界。

## 当前阶段

当前阶段只整理正式文档、冻结账务规则、建立匿名黄金测试并验证核心模型。客户端完整界面不早于核心规则和导入对账闭环。

## 当前非目标

- 完整 Android 和 Desktop 产品界面。
- Web、iOS 和其他扩展平台。
- 云同步服务和并发冲突协议。
- 具体 AI 服务接入。
- 会员、支付、广告、增长和遥测。

## 成功标准

- 正式交易按币种形成平衡分录。
- 余额可以从有效分录确定性重放。
- 来源事实、推断、人工确认和正式账目能够区分。
- 内部转账不会被统计为真实收入或支出。
- 修改、退款、冲回和对账均保留可解释历史。
- 匿名黄金案例在离线且未启用同步和 AI 时全部通过。
